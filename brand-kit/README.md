# Ship & Commit brand kit

Rendered from the site's own code: the glass 3D emblem, cream pastel light, ASCII sea and story typography (Inter + mono), so every graphic matches the website exactly.

| `x-header.png`, `x-header@2x.png` | 1500×500, 3000×1000 | X/Twitter header. The site also uses `public/branding/x-header.jpg` as the $SHIP banner fallback. |
| `avatar.png`, `avatar@2x.png` | 800×800, 1600×1600 | Profile picture (fits a circular crop). |
| `square.png` | 1080×1080 | Feed post: "Launch is easy. Shipping is everything." |
| `step-launch.png` … `step-release.png` | 1080×1080 | Five-part "how it works" thread/carousel (01 Launch, 02 Lock, 03 Commit, 04 Verify, 05 Release). |
| `cta-vertical.png` | 1080×1920 | Stories / Reels / TikTok: "Ready to ship?" |
